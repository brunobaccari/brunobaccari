## O que levo para um projeto

- Estratégia de testes por risco, critérios de aceite e cobertura de regressão.
- Automação com relatórios no CI e evidências para investigar falhas.
- QA com Codex, Cursor e Antigravity: regras de projeto, skills reutilizáveis, diffs dos repositórios envolvidos e revisão dos testes gerados.
- Avaliação de respostas estruturadas de LLMs, com limites de cobertura explícitos.
