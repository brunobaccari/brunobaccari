## 🧠 How I approach quality

- Start with risk and expected behavior; choose the test boundary according to the integration involved.
- Review AI-generated tests against requirements, contracts and diffs. A generated test still needs a defensible expected result.
- Investigate failures before adding retries or changing expectations. Environment, automation and product failures need different fixes.
- Make results usable in CI: gates, summaries and artifacts for release decisions.
